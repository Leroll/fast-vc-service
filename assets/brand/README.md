维护者于 2026-11-03 确认使用深绿白波形图标 A，以及酸橙流动横版封面 D。两者由本次品牌设计过程中的内置 imagegen 生成，并获确认用于项目首页及文档网站；生成提示词和完整设计过程保存在独立品牌资产归档中。仓库不依赖该归档目录进行构建。

## 2. 使用与维护

完整图标母版为 711 × 711 PNG；导航与页签导出没有重新绘制轮廓。16 px 下细节受尺寸限制，未进行独立像素修形。当前没有对应的 SVG 矢量母版，历史候选不得作为定稿替代。

封面 D 是参考 A 图标生成的完整画面，可能存在细微生成差异；独立图标以已选母版的导出为准。保持原比例与留白，不拉伸、不镜像。

封面沿用 assets/cover.webp 路径，旧题图内容已替换；旧题图保留在仓库外的设计历史归档。完整母版、历史候选、对比图、提示词和额外尺寸导出统一存放在仓库外的独立品牌资产目录；仓库只保留上表三项实际使用资源与本说明，不保留 concepts 过程素材。

文档构建只复制表中三项资源到站内 brand/ 路径，具体规则见[文档网站设计](../../docs/zh/design/文档网站.md#3-路径与链接适配)。选型与验收见[品牌图标 Spec](../../docs/zh/specs/2026-11-02_1755__品牌图标设计/01__设计与验证.md#11-定稿与接入2026-11-03)。
