# 变更日志

## 1. 每日记录

实际有改动的北京时间日期建立 `YYYY-MM-DD.md`，同日追加，纯讨论和只读检查不写日志。记录实际改动、验证与限制，重要任务链接 Spec，不复制完整方案。

条目格式：

```text
1. **作者** · `HH:mm:ss` · 实际改动；验证结果与限制；相关 Spec。
```

作者取写入时本仓库 `git config --get user.name` 的有效值，未设置时询问用户。日期和时刻取首次实际写入的北京时间，不用提交或完成时刻代替，不填写 AI 工具名。

补记历史事实在实际补记日记录，并注明原日期与依据。更正以追加说明保留历史；合并保留原作者、时刻与事实，时间不能作为覆盖冲突的理由。冲突处理见 [协作规则](../../../AGENTS.md)。
