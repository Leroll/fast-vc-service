## 2. 目录与命名

新报告按实际测试开始时间归档到 `docs/evaluation/reports/YYYY-MM-DD_HHmm/`，统一换算为北京时间（UTC+08:00），精确到分钟。目录内使用硬件或测试主题命名 Markdown，例如 `4090d.md`；同一分钟的不同测试用有区分度的文件名保存。版本、提交与配置记录在报告内，不再作为目录名。

报告中注明实际测试时间及其时区，复现条件与指标口径遵循[评测指南](../README.md)。本索引收录经整理、可公开的评测报告；原始音频、日志、时间线及自动生成的运行报告仍按[结果保存与发布](../README.md#5-结果保存与发布)处理。
