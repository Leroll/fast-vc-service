## 2. 目录与维护

中文文档集中在 `zh/`，英文文档集中在 `en/`，两种语言的对应文档使用相同的主题分类。英文仅覆盖已约定的翻译范围，历史资料保留原文。

`website/` 是两种语言共用的网站工程。本页用于仓库内导航；网站首页由 `zh/README.md` 生成，中文网址保持根路径，英文保持 `en/` 路径。

写作、翻译范围及同步规则见[文档维护](zh/maintainers/documentation.md)，预览与验证见[文档网站](zh/design/文档网站.md)。
