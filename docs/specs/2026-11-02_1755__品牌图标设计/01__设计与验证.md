当前进展：用户于 2026-11-03 选定深绿白波形图标 A，以及酸橙流动横版封面 D，并授权正式接入 README 与文档网站。定稿接入见[第 11 节](#11-定稿与接入2026-11-03)，资产归档与清理见[第 12 节](#12-设计过程资产移出仓库)。此前章节保留各轮探索时的决策、文件名和验证；过程图片及提示词已移至独立品牌资产归档，不再作为仓库链接。

## 1. 背景与目标

现有题图通过波形穿过转换挡板说明实时音色转换，但横向场景和细节不适合缩成独立图标。本次先研究成熟项目与设计案例，再制作品牌图标候选稿。交付用于讨论和选择；不修改现有题图、README 或在线网站。

## 2. 已确认的设计方向

用户先选择简洁且有辨识度的专业符号，随后明确要求彩色，并指定“波形 → 中间挡板 → 另一种波形”的结构；进一步要求可爱、像流动的水一样的波形。以这些后续要求为准。

采用圆润、饱满的水流状波形，转换前后同时改变颜色和波形轮廓；中央是一片可见的圆角薄板。结构尽量接近方形，保留明确留白。当前文档站的酸橙色不作为本轮图标配色限制。

用户随后否定第二轮蓝橘、蓝粉概念稿的视觉效果。第三轮继续保留已确认的语义结构，改为平面的有机曲线与干净色块，缩小挡板、收紧横向跨度，去掉高光和塑料质感。可爱感通过比例和曲线表达，不再用软糖般的材质表现。下面第二轮视觉判断仅保留当时记录，不代表用户认可或当前推荐。

## 9. 同色波形的音色差异探索

用户希望两段波形使用同一种颜色时，仍能表达不同音色，并同意分别生成各个方向的候选。上一轮左侧主波峰较宽、右侧波峰较密，容易被理解为音高变化；本轮目标是让两侧的主要周期和高度接近，改用周期内部的形状差异表达转换。这是品牌图形的视觉隐喻，不是由真实音频计算得到的波形或音色分类图。

沿用第四轮 B 的酸橙底白色图形、F 的酸橙底深绿图形，以及向右倾斜的圆角外框和中央斜切间隙。每个方向各做两种配色，共六版：A1 / A2 改变右侧外轮廓，在圆滑波峰上加入圆润的小肩部；B1 / B2 保持相近外轮廓，只在右侧加入一条内部曲线留白；C1 / C2 改变右侧曲线的升降走势，采用缓升、较快下降的不对称曲线。全部保持圆润水流感，左右使用相同前景色，不以大小、颜色或新增完整波峰作为主要区分。

先通过内置 image_gen 分别编辑候选，再比较轮廓区别、中央间隙、外框边界和缩小后的辨识度。保存独立原图、完整提示词与编号对比图；不覆盖此前候选，不直接替换网站素材。
