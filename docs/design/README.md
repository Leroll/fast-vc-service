# 当前设计

## 1. 阅读入口

本组文档按仓库 `d0ccdfe` 中的源码与配置（包版本 `0.1.7`）核对，采用一篇总体设计和七篇模块设计。模块按职责划分，与源文件、类并非一一对应；本轮只整理文档，未重构代码或执行运行验收。

| 文档 | 内容 |
| --- | --- |
| [总体设计](总体设计.md) | 定位、七个模块的边界、音频主链路与资源归属 |
| [服务启动与运行配置](服务启动与运行配置.md) | 配置加载、启动顺序、Worker 与设备分配、进程管理 |
| [接入与协议适配](接入与协议适配.md) | WebSocket 收发、协议归一化、结束与错误路径、HTTP 路由 |
| [会话与状态管理](会话与状态管理.md) | 会话创建、上下文与状态更新、资源释放 |
| [音频输入与缓冲](音频输入与缓冲.md) | 音频表示、解码、输入重采样、分块、预填充与尾块 |
| [流式转换流水线](流式转换流水线.md) | VAD、滑动窗口、音高、检索、推理、RMS、SOLA 与输出 |
| [模型与参考音色](模型与参考音色.md) | 模型组件、权重与缓存、参考条件预计算及复用 |
| [数据记录与可观测性](数据记录与可观测性.md) | 音频保存、日志、连接统计、时间线与指标限制 |
| [历史归档](archive/README.md) | 原始原理笔记、历史路线与迁移对照 |

先读总体设计，再按问题选择专题：首块等待与尾部处理从音频缓冲进入，连续转换效果从流水线进入，连接结束与状态回收从接入和会话进入，运行诊断从数据记录进入。

仓库配套设施：[文档网站](文档网站.md)说明内容与同步检查、MkDocs 构建、链接适配和 GitHub Pages 自动发布；[维护入口](../maintainers/README.md)集中贡献规则与工程记录。

## 2. 与其他文档的分工

对外字段与消息由 [API](../api/README.md) 维护，启动命令与配置由[操作指南](../getting-started/configuration.md)维护，测量方法见[评测指南](../evaluation/README.md)。此处说明内部职责和约束，不复制完整参数表。

模块文档统一说明职责与边界、输入输出、关键流程和约束，并指向实现源码。跨模块约定在所属专题详细维护，其他文档摘要并链接；行为变化应同步对应专题与总体设计。

任务方案与验收写入 [Spec](../specs/README.md)，实际变化记入 [changelog](../changelog/README.md)。已实现、限制与演进方向分开标注；旧路线不自动成为已接受需求。
